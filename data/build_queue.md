# Build queue — ordered by Australian intern MCQ/OSCE yield

**Status lives in `PENDING_GUIDELINE_CHECKS.md`.** This file is the *order*, not the
record. Work top down. Mark items done in the tracker, not here.

**Ranking basis:** frequency an intern meets it × consequence of getting it wrong ×
whether it is examinable in an AMC MCQ or performable in an OSCE. Australian-specific
content is weighted up — it is what an AMC exam tests and what overseas resources
cannot supply. Items where the corpus already teaches a condition but omits its
test, antidote or classification are weighted up too: exams test the pair, and the
half-covered set is what makes them look covered.

**Sourcing standard unchanged:** 3 agreeing independent sources for any dose,
threshold or timing window; 2 for non-numeric. Disagreement → omit and log.
